# Smart Task Board 🧠📋

A real-time collaborative task board built with the MERN stack (MongoDB, Express, React, Node.js) — featuring drag & drop, smart task assignment, activity logs, and conflict handling.

---

## 🌐 Live Demo

> 🔗 [Frontend on Vercel](https://your-frontend.vercel.app)  
> 🔗 [Backend on Render](https://your-backend.onrender.com)

---

## 🚀 Features

- 🔐 User authentication (Register & Login)
- 📋 Create, edit, and delete tasks
- 🧲 Drag & drop between Todo / In Progress / Done
- 🧠 Smart Assign to balance team workload
- ⚔️ Real-time conflict handling (with alert)
- 🔁 Live updates via Socket.IO
- 📜 Activity log (last 20 actions shown)
- 🌈 Fully responsive, modern UI (Tailwind + custom)

---

## 📦 Tech Stack

**Frontend:** React + Vite + Tailwind CSS  
**Backend:** Node.js + Express + MongoDB + Mongoose  
**Realtime:** Socket.IO  
**Auth:** JWT  
**Deploy:** Vercel (frontend) + Render (backend)
